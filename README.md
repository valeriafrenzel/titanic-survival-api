# Titanic Survival Predictor — учебный деплой-проект

Небольшой сервис на FastAPI: по данным пассажира (класс билета, пол, возраст, стоимость билета и т.д.) предсказывает вероятность выживания. Модель — логистическая регрессия внутри Pipeline (масштабирование числовых признаков + OneHotEncoder для категориальных).

**Качество на тестовой выборке:** accuracy 0.80, ROC AUC 0.84.

Цель проекта — не сама модель (данные учебные, всем известные), а демонстрация полного цикла: от обучения до рабочего API, который можно вызвать по сети.

## Как запустить локально
```
pip install -r requirements.txt
uvicorn app:app --reload
```
Открыть http://localhost:8000/docs — там автоматическая документация и кнопка «Try it out».

## Пример запроса
```
POST /predict
{
  "pclass": 1,
  "sex": "female",
  "age": 25,
  "sibsp": 0,
  "parch": 0,
  "fare": 100,
  "embarked": "C"
}
```
